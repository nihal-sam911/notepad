#Graphite

A lightweight, distraction-free desktop note-taking application built with Python and Qt.

Features
Cross-Platform: Runs natively on Linux, Windows, and macOS.

Built-in Themes: Supports customizable QSS themes (Light, Dark, Sepia, Midnight Blue, Hacker, Rosé Pine, Gruvbox, Evergreen).

Minimalist UI: Features a collapsible sidebar, clean typographic alignment, and a distraction-free text editor.
